## 一、定位与排版

轻量首页 = 品牌条（含常驻搜索触发器）+ 一句主张「想找什么，直接敲。」+ 大搜索入口 + 「最近收录」4 条真实条目 + 备注/页脚。**查找全部发生在命令面板里**，首页不做分类卡片墙，与正式站（方案参照 v3 首页）形成明确差异。

延续协会品牌：暖纸底 `#f3eee3` + 墨黑 `#1b1813` + 协会红 `#b02a22`，浅网格背景、等宽字体做 kicker/键帽/日期，标题四字用 `assets/title-sc.ttf`（unicode-range 只覆盖「电创导航」四字，其余回落系统宋体/黑体）。桌面内容栏 1060px 居中；手机单列、日期列隐藏、副标题单行截断。

## 二、数据与路径

- `links-data.js` 是正式站 `data/links.js` 的**原样副本**（`window.NAV_DATA`），未编造任何资源：6 分类（硬件/软件/学习路线为空，按数据如实显示空态文案）、4 条目 = 技本高数合集（4 资料包）+ 塔克 DAP 资料 + MSPM0/ESP32-S3 两个引脚规划器。
- 合集 4 个资料包直链 GitHub Release zip（52 KB / 7.8 MB / 620 KB / 8.3 MB），「查看全部资料包」指向 Release tag 页；DAP 附淘宝购买链接；全部外链 `target="_blank" rel="noopener noreferrer"`。
- 站内相对链接（`tools/*.html`）经 `resolveUrl` 加 `../../` 回到仓库根，file:// 下实测解析正确、能打开真实工具页。
- 排序与正式站一致：updated 倒序、同日期数据靠后者在前；搜索为多词 AND、标题命中加权、子串高亮。

## 三、核心交互（实测口径）

### 唤起与搜索
- `/`（非输入态）或 `Ctrl/Cmd+K` 或点击顶栏/大搜索按钮 → 命令面板，焦点入输入框并全选。
- 输入即筛（名称/说明/标签/来源/分类/资料包名都参与匹配），分类 chips（全部/课业传承/器件手册/在线工具，带计数）叠加筛选；空结果有引导文案，Enter 无副作用。
- `↑↓` 循环选择（combobox + aria-activedescendant），`Ctrl+Home/End` 首尾。

### Enter 行为一致
- 面板内 `Enter` = 预览选中项；`Ctrl/Cmd+Enter` = 直接新标签打开主链接。
- 鼠标点选 = 预览（Ctrl+点 = 直接打开）；首页点条目 = 直接开预览。
- 预览标题上 `Enter` = 打开该条目主链接；预览内按钮/链接上的 Enter 保留原生激活（钉住/关闭/下载某包）。
- 主链接规则：普通条目用 `url`（文案取 `urlLabel`，默认「资料下载」）；合集用 `allUrl`（「查看全部资料包」）。

### 详情预览（不长期遮挡主操作）
- **宽桌面 ≥1280px**：右上悬浮卡（400px），非模态（aria-modal=false），与面板共存；遮罩让出右栏 440px，预览不被压暗、随时可点可关。未钉住时 ↑↓/悬停切换选中项会跟随刷新预览内容（快速浏览）；`Ctrl+P`（面板内）或 `P`（焦点在预览内）或点钉住钮 → 钉住，内容不再被替换，可对照着继续搜。Tab 把面板+预览纳入同一焦点圈，可从搜索结果直接 Tab 进预览钉住/下载。
- **中等桌面 721–1279px**：放不下并排两栏，预览打开时面板整体让位隐藏（visibility:hidden，记住输入词），焦点移入预览；关预览自动恢复面板和查询词接着搜；再按 Ctrl+K 也会收预览回面板。这是本次续作新增的规则，避免悬浮窗盖住搜索主操作。
- **手机 ≤720px**：预览改为**底部抽屉**（贴底全宽、圆角顶、grip 条、最高 78dvh、内部滚动），模态：遮罩 + body 锁滚动 + Tab 圈定；与面板互斥（开一个先收另一个）；抽屉无钉住概念（钉住钮隐藏），抽屉本身就是停留态。点遮罩/Esc/关闭钮收起并解锁滚动。

### Esc 分层与焦点归还
- 手机：Esc 先关抽屉（面板本就互斥不在）。
- 桌面焦点在预览 → 只关预览，面板留着继续搜（焦点回输入框）。
- 桌面焦点在面板 → 关面板；未钉住的悬浮预览随之收起；**钉住的保留**并把焦点接进预览标题，再按一次 Esc 收掉。
- 所有关闭路径都归还焦点：面板还给唤起元素（触发按钮/条目按钮），预览还给输入框或唤起元素；归还目标已隐藏时兜底到预览标题或顶栏触发器，绝不落 body。
- 跳过链接、`:focus-visible` 红色描边、程序焦点锚点（预览标题 tabindex=-1）均就位；prefers-reduced-motion 下所有动画/过渡 ≈0。

## 四、实测（Playwright + 本机 Edge，file:// 页面）

自动化脚本共 **85 项断言全部通过**（desktop 1440×1000 / mid 1000×800 / mobile 360×800 触屏仿真 / reduced-motion 四个上下文），关键项：

- 聚焦/快捷键：`/`、`Ctrl+K` 唤起且焦点在输入框；空查询 4 条；「引脚」命中 2 个规划器且高亮；「高数」命中 1 条合集。
- 上下键：切换、末尾回绕、反向均验证 aria-activedescendant。
- 预览/打开：Enter 开预览且焦点留输入框；未钉住 ↓ 跟随刷新；Ctrl+Enter 真实弹出新标签（GitHub Release 页加载成功）；返回后面板/预览/查询词「高数」原样保留。
- 钉住/关闭：Ctrl+P 钉住后 ↓ 内容不动；Esc① 收面板留钉住预览并接焦点；预览内裸 P 取消钉住；Esc② 收预览归还焦点到触发器；鼠标点选/关闭钮路径同样验证。
- 合集真实性：4 个资料包 href 与数据逐字一致、大小标注正确、`_blank+noopener`；点击资料包**实际触发下载**，捕获到 release-assets.githubusercontent.com 的真实 zip（jiben-gaoshu-d1-shang-qimo.zip / …qizhong.zip），下载后返回预览/抽屉状态保留。
- 手机抽屉：贴底全宽（bottom=800,left=0,width=360）、模态+遮罩+锁滚动、焦点入标题、Tab 圈定 10 次不逃逸、Esc 解锁并归还焦点、遮罩点击关闭、抽屉↔面板互斥。
- 溢出：1440/1000/360 各状态 `scrollWidth ≤ innerWidth` 全过；全程无 pageerror。
- reduced-motion：面板/预览 animationDuration ≈ 0（1e-05s）。
- 工具相对链接解析到仓库根 `tools/mspm0-pin-planner.html`（不含 /previews/），预览标题 Enter 实测打开了真实 ESP32-S3 工具页（file://）。

## 五、取舍与简化（按要求说明）

1. **不做详情页路由**：正式站的 `#/i/<id>` 深链、资料包 id 定位未实现——原型以预览替代详情页，减少一层跳转；代价是无法分享某条目的固定地址。
2. **中等桌面用「让位」而非并排**：721–1279px 不硬塞两栏，预览开时面板暂隐、关时恢复。比缩放面板更简单可靠，代价是该区间不能边看预览边改关键词（需先关预览或 Ctrl+K）。
3. **手机抽屉不做拖拽手势**：只有 grip 视觉提示 + 遮罩/Esc/关闭钮，未实现下滑关闭，避免为悬浮窗堆功能。
4. **钉住不持久化**：刷新即重置，不写 localStorage；原型阶段够用。
5. **空分类不出现在筛选 chips**：硬件/软件/学习路线 0 条，chips 只列有内容的分类（计数如实），首页统计仍显示 06 分类。
6. 搜索为朴素子串 AND + 标题加权，无拼音/模糊纠错；数据量 4 条足够。
7. toast 仅作「已在新标签页打开/已钉住」轻反馈，2.2s 自动消失，不挡操作。

## 六、已知不足

- 屏幕阅读器对「面板+非模态预览共存」的双层结构播报顺序未做真机读屏验证（ARIA 角色/焦点管理已按规范实现，但 NVDA 实测缺席）。
- 手机抽屉最高 78dvh，长合集需内部滚动，第 4 个资料包首屏不可见（可滚到，主按钮常驻底部）。
- 中等桌面让位瞬间面板消失略突兀（无过渡动画衔接，reduced-motion 一致性优先）。
- file:// 下 `window.open` 的 noopener 由浏览器保证；若未来部署到 http(s)，行为不变但未在该环境复测。
- 首页「最近收录」只有 4 条真实数据，列表形态在数据增多后的分页/分组未设计。
