数据为真实站点数据的原样副本 `links-data.js`（与 `data/links.js` 逐字一致，未编造条目）；品牌资产复制在 `assets/`。

## 一、融合思路：A 的骨架 + B 的搜索入口，去掉 B 的悬浮预览

- **骨架 = A**：左栏分类 + 当前结果目录（OUTLINE），中栏结果列表，右栏当前资料详情；三栏共享 `{分类, 查询, 选中}` 状态，任何一处操作同步另外两处。保留连续上一条/下一条比较、合集 4 资料包、真实外链、空态、hash 直达快照。
- **搜索 = B 的命令面板**：顶栏搜索是明显可点的触发器（红图标 + 边框 + `Ctrl K` 键帽）。点击、`/`、`Ctrl/Cmd+K` 打开居中模态面板并聚焦输入。**不做 B 的悬浮预览/钉住**——详情只有右栏一份，避免重复浮层。
- **面板选中 = 回写三栏**：Enter/鼠标点选关闭面板，把所选条目定位进工作台（分类/列表/详情三处同步高亮），焦点落在定位到的列表卡片上，↑↓ 可继续比较。

## 二、命令面板与三栏状态规则（实测口径）

### 唤起与筛选
- 点击触发器 / `/`（非输入态）/ `Ctrl/Cmd+K` 打开；再按 `Ctrl/Cmd+K` 关闭。打开时整个工作台 `inert`，Tab 在面板内循环（实测 12 次不逃逸）。
- 面板**预填当前查询词**并全选；分类 chips 默认「全部」（全局搜索），只列有内容的分类（全部 4 / 课业传承 1 / 器件手册 1 / 在线工具 2），计数如实。
- 即时筛选：多词 AND，匹配名称/说明/来源/标签/分类名/**资料包名与说明**；标题命中加权排序，命中 `<mark>` 高亮；空结果有引导文案，Enter 无副作用。
- `↑↓` 循环选择（combobox + aria-activedescendant，末尾回绕），`Ctrl+Home/End` 首尾。

### 三种退出路径
| 操作 | 行为 |
| --- | --- |
| `Enter` / 鼠标点选 | 关面板 → **三栏定位**：查询词成为工作台查询；分类切到条目所属分类；选中该条目。toast 提示「已定位：××（查询「××」）」 |
| `Ctrl/Cmd+Enter`（或 Ctrl+点选） | 直接新标签打开真实主链接（普通条目 `url`，合集 `allUrl`），`noopener`；**不改工作台状态**，面板留着继续搜 |
| `Esc` / 点遮罩 / 关闭钮 | 取消面板，**工作台状态原样不动**，焦点归还唤起元素，绝不落 body |

### 跨分类定位的可理解性
全局搜索选中当前分类外的条目时，「**查询 + 条目所属分类**」一起回写：例如在「课业传承」下搜「引脚」选中 MSPM0 → 左栏切到「在线工具」、中栏变成「引脚」在该分类的 2 条结果、右栏显示 MSPM0 详情、步进器 2/2。所选条目必然出现在中栏列表里，查询上下文完整可见。

### 查询可见与清除
- 有查询时顶栏触发器变为「查询「高数」 · 点击修改」（红边强调），旁边独立 × 清除钮；中栏另有搜索状态行「「高数」 · N 条匹配 + 清除」。
- 清除只清查询，**保留当前分类与选中条目**；焦点回触发器。
- Esc 分层：面板开着先关面板 → 有查询清查询 → 有选中关详情（桌面取消选中回占位；手机收层保留选中，见下）→ 手机抽屉最先。
- hash 快照带查询：`#/i/<id>?q=<词>`，replaceState 写入不进历史栈。

## 三、右栏宽度：无固定上限、自适应、水平居中（第二轮修正）

上一版曾用 `max-width:1560px` + 左对齐，2550 下右侧偏空（左 40 右 286）。本轮**彻底去掉详情容器的固定宽度上限**：

- `.detail-doc` `width:100%; margin:0 auto`，随右栏实际可用宽度自适应；水平居中由 `.detail-scroll` 的**对称 padding**（`clamp(16px, 2.2vw, 40px)`）保证——2550 默认左右各约 40px（实测差值 ≤2px）。
- **阅读行长限制只加在正文/摘要**（`max-width:72ch`，宽屏分栏内 62ch），资料包网格和详情卡本身不设 1560 等上限，铺满整栏。
- 右栏因拖拽变窄时，容器查询（`container-type:inline-size`）按**容器实际宽度**自然切换：≥960px 双区（合集页头双列 + 2×2 资料包瓦片；普通条目说明/操作分栏），≥1400px 再放大一档，<960px 单列。手机 fixed 详情层用 `@media not all and (max-width:900px)` 显式排除容器查询，360 恒单列。
- 实测几何：1440 详情 712/776（92%）；1920 详情 1176/1256（94%）双区；2550 详情 ≈1806/1886（≥95%）、左右留白各 ~40px 对称、`maxWidth:none`、2×2 瓦片各 ~860px、摘要 ≤900px 不拉超长单行。

## 四、左栏目录：只定位不下载（第二轮修正）

OUTLINE 中「大一上期中/期末」等资料包项**全部改为 `<button>`**（原来是直接下载外链）：

- 点击 / Enter / Space → 选中父合集（如未选中，静默选中不抢焦点）→ 关闭移动抽屉（如开着）→ 右栏/手机详情**滚动到对应资料包瓦片**并给**清楚但不过度的定位高亮**（红边 + 浅红底 + 左侧红条，2.4s 后自动褪去），焦点落在瓦片上。
- **不触发 window.open、外部导航或下载**（实测监听 download/popup/URL 全程为 0）；真正下载只发生在右侧资料卡瓦片/主操作。
- 刚被定位的父合集在目录中保持子包展开（高亮可见），高亮褪去后恢复随选中展开。
- 手机：抽屉里点子包 → 收抽屉 → 全屏详情滚到瓦片；「返回列表」保留选中（卡片红边标示刚才位置），目录子包随之保持展开，方便接着定位下一个包。

## 五、两条可拖分隔条（第二轮新增，第四轮收敛）

桌面左栏↔中栏、中栏↔右栏各一条分隔条（`#resize-left` / `#resize-mid`）：

- **CSS 变量控宽**：拖动写 `.workbench` 的 `--col-left` / `--col-mid`，grid 列模板 `var(--col-left) 7px var(--col-mid) 7px minmax(0,1fr)`，右栏吃掉剩余空间。只改 DOM 样式变量、不进 state/render，**搜索/切换条目/开关面板不会复位**。
- **Pointer Capture**：`setPointerCapture` 支持鼠标/触控，`touch-action:none` 防滚动打断；手柄 hover/拖动时红色竖线 + 中央握把可见。
- **min/max 钳制**：左栏 200–420、中栏 280–560，且动态保证**右栏至少 320px**（按当前另一栏宽度实时收紧 max），拖到极端也不横向溢出、右栏不被挤没。
- **不支持键盘调宽（第四轮移除）**：手柄无 tabindex、不可 Tab 聚焦；方向键/Home/End/Enter/Space 监听器整体删除；title 只写「拖动调整××栏宽度；双击复位」。`role=separator` + `aria-orientation` + `aria-valuemin/max/now` 保留为**当前宽度的只读描述**（拖动时同步），不伪装成键盘可操作。实测 Tab 30 次不落在分隔条、对元素派发按键事件列宽不变。
- **双击复位**回默认 264/400（title 与本文均有说明）。不持久化（刷新回默认）。
- **仅桌面显示**：≤900px `display:none`，手机分层不受影响（实测 360 无分隔条）。
- **容器查询响应**：1920 下把中栏拖到 max 560 + 左栏拖到 max 420 → 右栏 926px <960 → 资料包自动切单列；双击复位 → 恢复双列（实测断言）。

## 六之二、右栏空态：开放式引导（第三轮重设计，第四轮改开放）

第三轮曾做 660px 居中小卡，用户仍觉偏下、小气。第四轮改为**开放式**，不再做卡片：

- **无边框 / 无卡片底色 / 无阴影 / 无装饰线**：`.detail-placeholder` border:0、background:none、box-shadow:none，直接落在右栏网格衬底上（实测 computed 全为 0/none/transparent）。
- **水平居中、视觉重心 ~45%**：`.detail-scroll.is-empty` flex 居中，内容块再 `translateY(-5vh)` 上移——几何 50% 居中会显偏下，实测 1440 重心 42.8%、2550 43.4%（断言区间 42–48%）。
- **宽松舒展排版**：内容区宽 860px（max-width:100% 随空间收缩，360 不溢出），图标 52px、标题 1.5rem、正文 1rem/1.75 行高，适度而非夸张。
- **快捷键开放一行/自然换行**：`.ph-keys` flex wrap 居中，无包围卡片、无分隔线，仅真实 `<kbd>` 键帽保留边框。未选中态**只留三组准确键位**：`/` 或 `Ctrl+K` 搜索与定位；`↑↓` 切换资料；`Esc` 关闭详情。**「←→ 微调分隔条·双击复位」整组及任何同类描述已删除**（空态与全文均无）。Enter 行为不确定故不加。
- **三种语义一致轻量样式**：未选中（book 图标+三组键位）；空分类（archive 图标+「查看全部资料」按钮+搜索键位）；无结果（search 图标+「清除搜索」按钮+重搜键位）。按钮保留且语义各自正确。
- **实际详情不受影响**：选中后 `is-empty` 移除，详情恢复 fluid 自适应铺满（实测重选后占宽 ≥95%）。

## 七、手机端（≤900px）

列表页为主，汉堡开**目录抽屉**（dialog + aria-modal + inert + Tab 循环 + Esc/遮罩/关闭钮退出且焦点归还），点条目进**全屏详情层**（← 返回列表 + 上一条/下一条保留）。命令面板贴顶全宽，输入 16px 防 iOS 缩放；面板定位后直接进全屏详情（焦点入标题）。**返回列表保留选中**（与桌面 × 取消选中语义区分），焦点归还原卡片且抑制 focusin 联动避免误重开。详情层开合只由用户动作控制，步进/轻量更新不误关层。

## 八、典型操作路径

1. **快速找试卷**：`Ctrl+K` → 「高数」→ Enter → 三栏定位到合集 → 右栏 2×2 瓦片点「大一上期末」下载；或左栏目录点「大一上期末」**只定位**到该瓦片（高亮 2.4s），确认后再点瓦片下载。
2. **比较两个引脚规划器**：`/` → 「引脚」→ ↓ 选第二条 → Enter → 分类自动切到在线工具 → ↑↓ 原地切换详情 → 「打开工具」进真实工具页。
3. **调栏目宽度**：拖左边界加宽分类栏、拖中边界收窄列表栏，右栏详情随之变窄并在 <960px 时自动切单列；双击分隔条复位。
4. **反悔**：面板 Esc 随时取消，状态与焦点原样恢复；定位后 Esc① 清查询、Esc② 关详情。
5. **手机**：点搜索 → 「高数」→ Enter → 全屏详情 → 抽屉里点「大一下期末」→ 收抽屉、详情滚到该包高亮 → 返回列表（选中保留）→ 接着定位下一个包。

## 九、取舍与简化（及原因）

- **不做悬浮预览/钉住/第二浮层**：右栏已是常驻详情，面板只做「搜索→定位/直开」。
- **目录只定位不下载**：下载是有后果的动作，收敛到右侧资料卡单一出口，目录承担「看到哪、跳到哪」；避免误触下载。
- **手机返回保留选中、桌面 × 取消选中**：手机分层模型里「返回」是导航回退，保留位置感；桌面右栏常驻，× 是明确清空。
- **面板分类筛选不回写工作台**：chips 只影响面板内结果，定位时才写回条目所属分类。
- **Ctrl+Enter 不改状态**：直开不打断当前比较上下文。
- **分隔条不持久化**：原型阶段刷新回默认够用；宽度只写 CSS 变量不进 hash，避免污染分享链接。
- **hash 用 replaceState 快照**：点选不灌历史栈；代价是后退不能逐条回退点选。
- **搜索为子串 AND + 标题加权**：无拼音/模糊，与正式站一致。
- 未做：收藏、编辑、暗色模式、对比并排——超出本次目标。

开发中实际修掉的问题（如实记录）：
1. 面板列表重建后旧节点事件闭包下标错位 → 按条目对象 indexOf 定位。
2. 重建前残留 aria-activedescendant 指向已销毁节点 → 重建前显式移除。
3. 详情渲染曾隐式开关手机详情层 → 层开合收敛到用户动作。
4. 手机 fixed 详情误命中宽屏容器查询 → media 显式排除。
5. 普通条目元信息重复 → 全文只出现一次。
6. 手机「返回列表」焦点归还时底层尚不可见导致聚焦失败/误重开 → 延迟到滑出结束 + 抑制 focusin 联动；返回语义改为保留选中。
7. 抽屉里点子包时父合集未选中导致详情无瓦片 → locatePack 先静默选中父项再滚动定位。
8. 1560 固定上限 + 左对齐造成 2550 右侧偏空 → 去上限、对称 padding 居中。
9. 测试侧：外网加载失败覆写 popup.url（改断言 window.open 参数）；空查询排序 DAP 在第 3 位（按文本找索引）；站内 hash 快照变化不算外部导航（比较去 hash 的 URL）。
10. 空态卡被 flex 容器压缩到 ~510px 且上下 padding 不对称导致垂直偏心 → `flex:0 0 auto` + 固定宽/max-width:100% + 居中包裹层（第三轮）；第四轮改开放式后以 flex 居中 + translateY(-5vh) 精确控制视觉重心 ~45%。
11. 分隔条键盘调宽与「看似支持」的 tabindex/title 描述 → 整体移除监听器与 tabindex，ARIA 数值降为只读描述，title 只留拖动+双击复位。

## 十一、已知不足

- **数据量小**（4 条目/6 分类，3 空分类）：长列表、多合集、深目录未验证；2550 下详情内容少时右栏下部仍有网格衬底空白——数据现状，瓦片与分栏已提升信息密度。
- **分隔条不持久化**：刷新回默认宽度；如需记忆可后续加 localStorage。
- **replaceState 快照**不进历史栈，后退不能逐条回退点选。
- **面板 chip 不记忆分类**：每次打开回「全部」，只预填查询词。
- **外网依赖**：GitHub/淘宝链接真实性已核对到 URL 与下载行为，网络不可达时页面无法兜底。
- 仅本机 Edge（Chromium 内核）实测；Safari/Firefox 的 container queries/inert/pointer capture 为现代 baseline 特性，风险低但未逐一验证。
- 复制链接 file:// 下走 execCommand 降级，失败明示文案。
- 读屏真机（NVDA）未测；ARIA 角色/焦点管理按规范实现。
