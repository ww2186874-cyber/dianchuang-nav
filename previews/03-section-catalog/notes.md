## 信息架构：与其他方案的差别

不是「入口卡片 → 分类页 → 详情页」的三层跳转，而是**一张连续长页**：

- 6 个分类按数据顺序编号为 01–06 分区，全部同屏可达，滚动即浏览；
- 桌面左侧是**固定目录栏**（sticky），点击锚点跳转，滚动时自动高亮当前分区（scroll-spy），并显示「当前位置 · 04 课业传承」文字反馈；分区头部同步出现红色「● 正在浏览」标记；
- 空分类不隐藏，压缩成一行「待收录」占位（保留分类描述在 DOM 中、视觉收起），让目录编号稳定、结构可预期；
- 资料详情**不离开列表**：条目行是手风琴，点开在原位展开摘要、标签、来源/更新日期、下载按钮、合集资料包清单、附加外链；支持跨分区同时展开多条；
- 手机端目录收进右下角悬浮按钮（带当前分区名），点开是底部抽屉，不长期占屏。

查看路径对比：正式站看一份试卷要「首页 → 课业传承 → 详情页」三跳；这里只要「滚到/跳到 04 区 → 点开行 → 点资料包」，全程零页面切换。

## 核心交互逻辑

- **锚点**：目录链接平滑滚动到分区，落点预留固定页头高度 + 14px，标题不被遮挡；同时把焦点交给目标分区（tabindex=-1），读屏能感知跳转；hash 用 `history.replaceState` 更新为 `#sec-<id>`，可直接深链分享，刷新后仍定位到该分区。
- **当前位置**：scroll-spy 以「页头下沿 + 40px」为探测线；页尾加了约半屏留白，保证最后一个分区也能滚到锚点线，避免底部定位歧义。
- **搜索**：页头搜索框过滤全部分区（匹配名称/摘要/标签/来源/资料包名），命中文字 `<mark>` 高亮；顶部状态条报告命中数并给「清除搜索」；目录计数变成 `命中/总数`，无命中的分区置灰但仍可跳转；无结果时每个有数据的分区给出「没有匹配」说明。`/` 聚焦搜索，输入框内 `Esc` 清空。
- **手风琴**：行头是 `<h3><button aria-expanded aria-controls>`，详情是 `role="region"`；收起时加 `inert` + `visibility:hidden`，键盘不会 Tab 进折叠内容。展开动画结束后若行头被顶出视口会自动滚回；「收起详情」按钮把焦点归还行头。
- **外链**：所有资源链接 `target="_blank" rel="noopener noreferrer"`，本 tab 状态天然保留。数据里的相对链接（`tools/*.html`）按仓库根解析成 file:// 绝对地址，指向正式站点真实工具页。
- **状态持久化**：搜索词、展开条目集合、滚动位置写入 `sessionStorage`（滚动节流 150ms + pagehide/visibilitychange 兜底）。刷新、误关重开（同会话）都能恢复；搜索重渲染时以视口内第一行为锚保持滚动稳定。
- **移动抽屉**：`role="dialog" aria-modal`，打开锁 body 滚动、焦点入内并圈禁（Tab 循环 + focusin 陷阱），`Esc`/遮罩/关闭按钮都能关，焦点归还悬浮按钮；从抽屉跳锚点后焦点交给目标分区。
- **动效**：`prefers-reduced-motion: reduce` 时滚动改瞬时、过渡压到 0.01ms。

## 排版思路

冷白纸面（#f5f4ef）+ 墨青正文 + 朱红定位标记 + 深青辅助色，区别于正式站的暖纸工程网格风；等宽字体做编号/元信息，标题字体沿用协会 `title-sc.ttf`（仅「电创导航」四字）。左目录右内容的双栏在 ≤920px 折叠为单栏；≤560px 行右侧元信息栏换成摘要下方的紧凑元信息行，不丢大小/日期。

## 典型操作路径

1. **随便逛**：打开 → 滚动浏览 01–06 → 左侧目录实时告诉你走到哪 → 感兴趣的行点开看详情 → 再点一下或「收起详情」合上。
2. **找试卷**：目录点「04 课业传承」→ 点开「技本高数」行 → 4 个资料包按学期排好，点「大一上期末」新标签下载 → 切回来，展开和滚动都还在。
3. **搜工具**：按 `/` 输「引脚」→ 只剩两条工具且关键词高亮 → 点开行 → 「打开工具」新标签使用 → 返回后 `Esc` 清空搜索，之前展开的其他条目原样恢复。

## 取舍与简化（相对正式站）

- **去掉分类筛选 chips**：目录本身就是分类导航，再放一排筛选是重复控件；搜索直接作用于全部分区。
- **去掉独立详情页/合集页**：详情全部行内展开，这是本方案的核心假设；代价是没有 per-条目 的可分享 URL（分区级 `#sec-<id>` 深链保留）。
- **去掉「最近加入」侧栏**：条目行自带更新日期，长页里时间线索已经足够；避免和目录抢左侧空间。
- **去掉复制链接按钮**：原型阶段价值低；正式化时可以补 per-条目 hash。
- **空分类压缩但不删除**：保住目录编号与「这里将来会有什么」的预期；描述文字在窄版视觉隐藏（仍在可访问性树中）。
- 数据快照而非引用 `../../data/links.js`：保证目录整体拷走也能双击打开；更新数据需重新复制一次。

## 已知不足

- **无 per-条目深链**：详情展开状态只存 sessionStorage，换浏览器/新会话不保留；分享只能到分区级。
- **数据是快照**：`links.js` 不随正式站数据自动更新。
- **条目多起来后长页会变长**：当前 4 条很轻；若未来几十条，可能需要「分区内折叠/加载更多」，本原型未做。
- **搜索不含拼音/模糊匹配**：只做子串匹配，与正式站一致。
- **外链有效性未逐一验证**：下载/购买链接的真实可达性取决于网络与上游（测试中淘宝跳转到登录页，属上游行为）。
- **iOS Safari 未实测**：`inert`、`scrollTo behavior:'instant'`、`grid-template-rows` 过渡在旧版 Safari 可能降级（功能不受影响，动画/焦点圈禁可能变弱）；实测环境仅 Chromium。
- 页尾约半屏留白是为锚点定位服务的刻意设计，视觉上会有一段空白。
